# Learning notes

These are my own notes for learning and explaining this project, for example in an interview.

## Files

- `00-pitch.md`: a two-minute spoken pitch of the project. Updated at the end of every milestone.
- `NN-<concept>.md`: one note per concept, numbered in the order I meet them (e.g. `03-reciprocal-rank-fusion.md`).

## Note template

```md
# <Concept>

## What it is
Two or three sentences, in my own words.

## Why it is used here
What problem in this project it solves, and what the alternative was.

## What the experiment showed
The numbers from this project, with a link to the run or results table.

## Interview questions
- Q: ...
  A: ...
```

## Workflow

Claude drafts each note at the end of a milestone. I then rewrite it in my own words; the rewriting is where the learning happens. Vocabulary follows `GLOSSARY.md`, and decisions link to `docs/adr/` instead of repeating them.
